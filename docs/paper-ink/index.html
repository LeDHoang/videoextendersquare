ECHO Paper & Ink

3 Nov 2026 alts from redesign/editorial-ink @ 1e11447 Vite :5181 :5184 :5186 :5187 · headless Chrome · 1280 and 375 px

A closer look at the Paper & Ink redesign and two variants of it: one that swaps the cobalt accent for the app's own vermilion, and one that prints the same magazine in reverse, on a dark page with the vermilion accent. Both variants change colour tokens only; type, shape and spacing are Paper & Ink's. Every screenshot was taken in one run with the same viewport, wait and API data.

Scope

  • Web UI only. The reels player and the WebXR scene in ui/ keep the current look inside every variant.
  • Public pages only. The signed-in pages use the same tokens but nobody has looked at them.
  • The two variants are uncommitted changes in their own worktrees. Nothing is merged or pushed.

Checks

  • Both variants pass npm test (544 vitest tests plus node tests) and vite build. One HeaderBar test timed out once under load in the red variant and passed on a rerun.
  • Neither variant changes the CSS guardrail counts: the new colours live in tokens.css, which is exempt.
  • The reels shot picks a random reel on each load, so its video differs between looks.

What is left undone

All three looks

  • Reels player and VR. ui/ was off-limits, so the player chrome and the WebXR panels keep the current look.
  • Signed-in pages. Upload, Wallet, Messages, Settings and Moderation were never viewed.
  • Fragile logo. The logo is recoloured through CSS attribute selectors on the SVG, which breaks if the SVG markup changes.

The red variants

  • Accent and danger look alike. Vermilion and rose have nearly the same lightness (about 1.1:1), so they differ by hue only. The current app has the same trade-off; a colour-blind user may not tell a delete button from a primary one without its label or icon.
  • Two reds in the light variant. The page uses #c8270f and the dark reels area uses #ff3b1f, so the accent shifts slightly when a reel opens.
  • Dark variant on cards. Accent text on --sx-surface-2 is 4.9:1, close to the bar; small accent text on raised cards should be checked on the signed-in pages.
  • Not committed. Both variants are working-tree changes in .claude/worktrees/ink-red and ink-dark.
