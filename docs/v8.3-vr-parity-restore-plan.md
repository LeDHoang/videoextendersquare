## Confirmed control map (reels mode, right controller)

| Input | Behavior |
|---|---|
| Stick Y flick ↕ (no grip) | Next / prev reel (flick >0.5, reset <0.3; blocked on static cards) |
| Stick Y while pointing at comments panel | Scroll list ±6·thumbY/frame |
| Stick X flick ↔ (no grip) | Seek ±5 s |
| **Grip + stick Y ↕** | **Scale screen** 0.04/frame, clamp 1.0–10.0 m (locked or unlocked) |
| **Grip + stick X ↔ (NEW)** | **Distance: right = further, left = closer** (`screenDistance` default 2.24 m, clamp 1.2–6.0 m, 0.03/frame) |
| Grip held alone (unlocked only) | 6DOF drag & reposition, level-facing head |
| A / B buttons | Play/pause · Toggle dock+guide (edge-triggered) |
| Trigger | Laser click priority: panel → dock → popup comment → screen (play/pause + toggle UI) → empty (toggle UI) |
| 🎯 LOCK (default locked) | Head-locked perpendicular centered screen at `screenDistance`; unlock = free 6DOF |

## Deviation from legacy (documented, owner-visible)

Locked-mode dock/panel/guide are anchored at `{0, 1.52, −screenDistance}` and sized from **current `screenScale`**
(legacy froze them at the DEFAULT_POS/DEFAULT_SCALE spot — incoherent once distance/scale change).
Rationale: owner's "keep the control panel on top of the reel player" requirement.
